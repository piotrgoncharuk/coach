# Идеи за рамками задания

Сюда складываются мысли, которые возникли по ходу, но не входят в объём. Ничего из этого
не реализовано.

## Возникло на этапе 1

- **Размер сборки.** `@supabase/supabase-js` тянет около 120 КБ из 405 КБ бандла. Можно грузить
  его только когда синхронизация настроена и выполнен вход.
- **Проверка целостности.** Кнопка «сверить с сервером»: пересчитать количество подходов локально
  и на сервере и показать расхождение. Спокойнее, чем верить очереди на слово.
- **Часы устройства.** Если на телефоне сильно сбиты часы, его правки будут выигрывать конфликты.
  Можно сравнивать время устройства с временем сервера при входе и предупреждать.
- **Экспорт перед обновлением.** Автоматически складывать JSON-снимок в файл раз в неделю.
- **Калибровочная неделя.** Отдельный режим первой недели: приложение само предлагает проверить
  вес в 2–3 подходах и выставляет рабочие веса по результату.
- **Тёмная тема по расписанию.** Переключать по времени суток, а не только вручную.

## Возникло при настройке выкладки

- **Устаревший Node в экшенах.** `actions/checkout@v4` и `actions/setup-node@v4` работают на Node 20,
  который GitHub объявил устаревшим и принудительно запускает на Node 24. Это предупреждение,
  не ошибка. Поднять до `@v5`, когда будет возможность проверить теги.

## Возникло на этапах 2–6

- **Загрузка справочника в Supabase.** Скрипт, который сервисным ключом заливает общие
  упражнения в таблицу `exercises` — сейчас это ручной шаг из README.
- **Свои фото в облако.** Фото своих упражнений хранятся только на устройстве; с Supabase
  Storage их можно синхронизировать.
- **Перевод оставшихся инструкций.** Подробная техника по-русски есть у 49 упражнений;
  остальные 827 показывают оригинал.
- **Глобальная перестановка недели.** Планировщик снимает конфликты по одному; при футболе
  посреди недели между двумя днями ног лучше пересобрать всю неделю сразу.
- **Таймер для упражнений на время.** Планка и похожие идут в повторах-секундах; отдельный
  режим с обратным отсчётом подхода был бы удобнее.
- **Учёт свободного веса для подтягиваний и брусьев.** Сейчас вес — это доп. груз; можно
  учитывать вес тела в тоннаже и 1ПМ.
- **Предпросмотр сводки перед копированием.** Сейчас сводка сразу уходит в буфер, текст
  можно посмотреть ниже.
